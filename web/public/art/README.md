# Art, previews and social assets: provenance

Everything the asset pipeline puts in `web/public/` besides the official Flux marks in `web/public/brand/`
(which are never edited here). The typed manifest for all of it is `web/src/content/art.ts`, which is
generated: do not edit it by hand.

## Licence note

The files in `web/public/art/` are original generated artwork for this project. The files in
`web/public/previews/` are screenshots of the linked public apps and sites, captured at build time; they
belong to their respective owners and are used here only to show what each linked destination looks like.
The Flux marks and lockups come unmodified from the official brand kit.

## Generated art (`web/public/art/`)

Each piece was generated by the Codex CLI image generation tool through `scripts/imagegen.mjs`, using the
prompt recorded under the piece's id in [`assets-src/PROMPTS.md`](../../../assets-src/PROMPTS.md), then
post-processed by `web/scripts/optimize-art.mjs` (crop, black floor crushed to 0, smooth edge mask so the
outer ring is exactly `#000`, WebP at quality 86, AVIF where it is at least 15 percent smaller at equal
DSSIM). Originals are in `assets-src/raw/` and are not committed.

Every piece is light on pure black: composite with `mix-blend-mode: screen` (or additive blending in
WebGL). There is no text, logo or UI in any of them.

## Captured previews (`web/public/previews/`)

960x600 WebP, under 70 KB each, captured by `web/scripts/capture-previews.mjs` with the system Chromium at
a 1280x800 viewport (WebGL on, dark colour scheme), above the fold. The script never logs in, never clicks
a consent banner and never submits anything.

Snapshots, not live views: live numbers on a preview are from the capture date (2026-10-12). Re-run the
script to refresh. A preview is absent when its capture failed; the UI falls back to generated art.

## Regenerate

From the repository root (the machine needs the Codex CLI, ImageMagick, `avifenc`, `rsvg-convert` and the
system Chromium):

```sh
# 1. raw art, 35 to 40 s each, 4 at a time. Missing pieces only; --force redoes, --only picks.
node web/scripts/generate-art.mjs
node web/scripts/generate-art.mjs --force --only tier-nimbus

# 2. crop, mask, encode, rewrite web/src/content/art.ts
node web/scripts/optimize-art.mjs

# 3. app previews (about 90 s), also rewrites the PREVIEWS list in art.ts
node web/scripts/capture-previews.mjs
node web/scripts/capture-previews.mjs --only atlas

# 4. social cards and icons
node web/scripts/build-og.mjs
node web/scripts/build-icons.mjs

# docs: assets-src/PROMPTS.md is generated from assets-src/art-spec.mjs
node web/scripts/generate-art.mjs --prompts-md
```

To change a prompt, edit `assets-src/art-spec.mjs`, regenerate that piece with `--force --only <id>`,
look at it, then run step 2.
